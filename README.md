# MinMin School

Сайт онлайн-школы китайского языка: одна страница на русском, форма записи на бесплатную консультацию и отправка заявок в Telegram.

Адрес: https://minmin-school.vercel.app/

## Как устроен проект

```
src/                 исходники — правьте только здесь
  index.html         страница; рисунки обозначены пустыми <svg data-artwork="…"></svg>
  styles.css         все стили в одном файле, разделы в порядке страницы
  app.js             меню, вкладки программ, профили преподавателей, форма
  data.js            программы и преподаватели
  lead.js            проверка формы и текст сообщения для Telegram
  assets/            шрифты, фото преподавателей, SVG-рисунки (graphics/)
scripts/build.mjs    сборка src/ → dist/
server/index.mjs     сервер: раздаёт сайт и принимает заявки на /api/leads
tests/               автоматические тесты
docs/                дизайн, иллюстрации, источники фото, деплой; docs/history — архив итераций
vercel.json          настройки сборки для Vercel
Dockerfile           запуск с сервером (если понадобится бот), см. docs/DEPLOY-TIMEWEB.md
```

`dist/` — готовая к публикации версия. Она создаётся командой `npm run build` и в репозиторий не попадает. Сборка встраивает SVG-рисунки в страницу (один файл рисунка → все его копии на странице) и добавляет к CSS и JS хеш содержимого, чтобы у посетителей не оставалась старая версия.

## Локальный запуск

Нужен Node.js 20 или новее, внешних зависимостей нет.

```sh
npm run dev     # собрать с сервером заявок и запустить на http://127.0.0.1:4173
npm test        # тесты
npm run build   # собрать статическую версию dist/ (на Vercel: npm run build -- --with-server)
```

## Публикация

Сайт размещён на Vercel (бесплатный план Hobby). Каждый `git push` в ветку `main` собирает `dist/` командой `npm run build` и обновляет сайт примерно за минуту. Ничего вручную загружать не нужно.

## Форма и Telegram-бот

Заявки с формы приходят ботом **@minmin_school_leads_bot** в закрытую группу «Заявки с сайта · MinMin School». На Vercel это две функции: `api/leads.js` (принимает заявку с формы) и `api/telegram.js` (вебхук бота). Код общий с локальным сервером — `server/index.mjs`, `server/telegram-bot.mjs`.

При загрузке форма спрашивает `GET /api/leads`, подключён ли бот:

- **Бот подключён** — кнопка «Отправить заявку», заявка уходит в чат школы, посетитель видит «Заявка отправлена».
- **Бот не подключён** — форма готовит сообщение и предлагает открыть Telegram школы. Сайт не пишет «отправлено», пока передачи не было.

Подключить бота (один раз, токен вводится в терминале и сохраняется только в переменных Vercel):

```sh
npm run telegram:setup -- --chat -5587765085
```

| Переменная (Vercel → Production) | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_ID` | чат, куда приходят заявки |
| `TELEGRAM_WEBHOOK_SECRET` | случайная строка, по ней вебхук узнаёт Telegram |
| `SITE_ORIGIN` | необязательно: точный адрес сайта, например `https://minmin-school.ru` |

**Перенести заявки в другой чат:** добавить бота в новый чат и написать там `/chatid` — бот ответит ID. Затем поменять `TELEGRAM_CHAT_ID` и пересобрать сайт:

```sh
npx vercel@latest env add TELEGRAM_CHAT_ID production --force --no-sensitive
npx vercel@latest redeploy minmin-school.vercel.app --target production
```

Если группу превратят в супергруппу, у неё сменится ID — бот сам дошлёт заявку по новому ID, но переменную стоит обновить. Секреты не кладите в `src/`, `dist/` и репозиторий.

Сервер принимает заявку, только если страница открыта с того же адреса (или с `SITE_ORIGIN`), ограничивает тело запроса 8 КиБ, пропускает в чат не больше 20 заявок за 10 минут и не повторяет отправку автоматически. Ответы `/api/leads`: `200 sent`, `400 validation_error`, `403 origin_not_allowed`, `429 rate_limited`, `503 not_configured`, `502 telegram_error` / `delivery_unknown`. Тесты используют подменённый транспорт и не пишут реальным людям.

## Содержание

Четыре направления и шесть преподавателей — в `src/data.js`. Фото преподавателей настоящие (`src/assets/teachers/`, источники — `docs/PHOTO-SOURCES.md`). Разделы «Отзывы» и «Достижения учеников» содержат только «Будет позже». Цены, расписание, юридические документы и гарантии результата не выдумываются.
