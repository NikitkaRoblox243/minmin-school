# Иллюстрации MinMin

Исходники рисунков находятся в `src/assets/graphics/`. Это SVG с плоскими заливками и округлыми контурами. Фотографии преподавателей хранятся отдельно и не перерисовываются.

Облака чередуются в двух вариантах: `cloud.svg` — округлый узор жуйи с зелёной заливкой; `cloud-swept.svg` — вытянутое облако с крупными завитками, бумажной заливкой и зелёным следом ветра. Второй вариант используется справа на первом экране, в разделах о школе, методике, культуре и справа в футере; семь отдельных облаков сохраняют первый вариант. Оба имеют одинаковую область 240×90 и используют прежние правила размещения.

Палитра: бумага `#fffdf8`, светло-зелёный `#e6edcf`, красный `#b74337`, оливковый `#657640`, контур `#272c27`.

После редактирования SVG выполните:

```sh
npm run build
```

В `src/index.html` рисунок обозначается пустым элементом, например `<svg data-artwork="cloud" class="artwork-inline …" aria-hidden="true"></svg>`. Сборка подставляет в него атрибуты и содержимое файла `src/assets/graphics/cloud.svg`, а для переключаемых иллюстраций программ создаёт `dist/artwork.js`. Поэтому один рисунок достаточно поправить в одном файле — все его копии на странице обновятся.

Перед публикацией проверяйте рисунки крупным планом и в карточках сайта. Для людей важны связные шея, плечи и руки; для наушников — непрерывная дуга и соединение с амбушюрами; для ноутбука — совпадение краёв крышки, шарнира и основания. Контуры облачков должны обходить хвост последовательно, без возвратов по уже нарисованной нижней границе. Предметы, лежащие на столе, должны иметь понятную опору.

Проверка SVG как XML не заменяет просмотр изображения. Дополнительно проверяйте внутренние ссылки и уникальность ID после вставки рисунков в HTML, а затем переключение программ и выбор формата занятий в браузере.
