# Сервер с ботом на Timeweb Cloud (на будущее)

Сейчас сайт работает на Vercel как статический, а форма готовит сообщение для Telegram. Эта инструкция нужна, только если захотите, чтобы заявки приходили боту автоматически. App Platform с сервером платный: цена видна при создании приложения.

Сайт и приём заявок работают как одно Node-приложение в контейнере (`Dockerfile` в корне). Timeweb собирает его из репозитория на GitHub и при каждом новом коммите обновляет сам.

## 1. Бот для заявок (5 минут, в Telegram)

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя (например «MinMin заявки») и username, оканчивающийся на `bot`.
2. BotFather пришлёт **токен** вида `123456789:AA…`. Это пароль бота: никому его не пересылайте и не вставляйте в код.
3. Решите, куда будут приходить заявки:
   - **в личку** — напишите своему боту `/start`;
   - **в группу команды** — создайте группу, добавьте туда бота и напишите в группе `/start@имя_вашего_бота`.
4. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (подставьте свой токен). В ответе найдите `"chat":{"id":…}` — это **ID чата** (у групп он отрицательный, например `-1001234567890`).

## 2. Приложение в Timeweb Cloud

1. [timeweb.cloud](https://timeweb.cloud) → **App Platform** → **Создать**.
2. Подключите GitHub и выберите репозиторий сайта, ветку `main`.
3. Тип / фреймворк — **Dockerfile**. Путь к директории проекта оставьте пустым (Dockerfile в корне репозитория).
4. Регион и самая маленькая конфигурация — сайту этого достаточно.
5. **Расширенные настройки → Переменные**:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHAT_ID` — ID чата из шага 1.
6. Путь проверки состояния (если спросят): `/api/leads`.
7. **Запустить деплой.** Логи — на вкладке «Деплой». Готовый адрес (технический домен с HTTPS) — на вкладке «Дашборд».

## 3. Проверка

1. Откройте сайт → блок «Запись на бесплатную консультацию». Кнопка должна называться **«Отправить заявку»** (если «Подготовить сообщение» — сервер не видит переменные бота, проверьте шаг 2.5 и перезапустите деплой).
2. Отправьте тестовую заявку — она должна прийти в выбранный чат.

## Свой домен

Привяжите домен в настройках приложения Timeweb (SSL выпускается бесплатно). После этого можно добавить переменную `SITE_ORIGIN=https://ваш-домен.ru` — тогда заявки будут приниматься только со страницы на этом адресе.
