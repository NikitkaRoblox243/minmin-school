# MinMin School Implementation Plan

> **For agentic workers:** Use subagent-driven development with explicit file ownership and independent final review. Track completed tasks here.

**Goal:** Build and privately publish a polished Russian MinMin School website with real teacher photographs, generated illustrations and working consultation flow.

**Architecture:** Buildless HTML/CSS/ES modules under `sites/minmin-school/dist`. Browser form prepares a Telegram message; an optional server adapter enables future bot delivery without exposing secrets.

**Tech Stack:** Semantic HTML, CSS, JavaScript ES modules, Node built-in test runner, WebP and local fonts, Sites hosting.

**Spec:** `docs/superpowers/specs/2026-10-09-minmin-design.md`

## Global Constraints

- Russian copy grounded in client correspondence.
- Reviews and achievements show only their headings and «Будет позже».
- Never invent missing prices, age limits, duration, legal documents, testimonials or credentials.
- Form must never falsely claim delivery; no real Telegram messages during QA.
- Responsive at 375/768/1024/1440; visible focus and reduced motion.
- Each agent owns separate files; root owns composition, CSS, assets, Sites and integration.

Files: `dist/data.js`, `dist/lead.js`, `dist/app.js`, `server/telegram.mjs`, `tests/lead.test.mjs`, `tests/telegram.test.mjs`.

Interfaces: `data.js` exports `programs` and `teachers`; `lead.js` exports `validateLead(input)`, `buildTelegramDraft(input)` and `buildTelegramUrl(input)`. `app.js` attaches to explicit DOM hooks provided by the page. Browser fallback only prepares a draft. Adapter reads secrets from environment and checks Telegram's response before claiming success.
