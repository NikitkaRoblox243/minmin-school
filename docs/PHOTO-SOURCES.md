# Источники фотографий

Проверка: 10 октября 2026 года. Для сайта получены настоящие JPEG-вложения из рабочего чата MinMin School в Telegram через `viewer img.downloadMedia`. Это файлы скачанных вложений, а не снимки экрана. Самые крупные доступные версии имеют высоту 1280 px; под исходником в этой проверке понимается полученный файл вложения Telegram.

Публикуемые файлы: `src/assets/teachers/`. Они побайтно совпадают с исходными вложениями (проверено 13 октября 2026 года), поэтому отдельная копия оригиналов не нужна. ## Предыдущий экспорт

В `artwork-originals/teacher-photos/` остаются старые PNG из Telegram viewer и сведения об их происхождении в `provenance.json`. Их размеры: Маргарита 462 × 694, Дарья 522 × 694, Мира 520 × 694, Мария 470 × 694, Лилия 470 × 626, Лися 520 × 694. Старые WebP в `dist/assets/teachers/` были сделаны из этих кадров с `quality=88`; они удалены из публикуемых ресурсов после переключения всех ссылок на JPEG. Эти файлы не являются выбранными исходниками для новой версии.
